# Photography

BOWER is a fictional restaurant built as a portfolio demonstration.
Every photograph here is a free-licence Unsplash image, downloaded by
`npm run images` and cut to the exact size the layout expects.

None of it is client-owned. On a real build these slots are replaced with
the venue's own photography at the same dimensions — no code changes.
